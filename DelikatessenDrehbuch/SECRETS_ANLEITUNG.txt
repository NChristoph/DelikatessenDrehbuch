========================================
CONNECTION STRING SICHER SPEICHERN
========================================

Es gibt 3 Möglichkeiten:

---
OPTION 1: User Secrets (EMPFOHLEN) ⭐
---
Führen Sie eine dieser Dateien aus:
• set_connection_string.bat (interaktiv - fragt nach Connection String)

ODER verwenden Sie diesen Befehl direkt:

  cd C:\Users\Free8\source\repos\DelikatessenDrehbuch\DelikatessenDrehbuch
  dotnet user-secrets set "ConnectionStrings:DefaultConnection" "IHR_CONNECTION_STRING_HIER"

Vorteile:
✅ Wird NICHT in Git eingecheckt
✅ Nur auf Ihrem Computer verfügbar
✅ Überschreibt automatisch appsettings.json


---
OPTION 2: Umgebungsvariable
---
PowerShell als Administrator:

  [System.Environment]::SetEnvironmentVariable('DB_ConectionString', 'IHR_CONNECTION_STRING_HIER', 'User')

Danach Visual Studio NEU STARTEN!

Vorteile:
✅ Funktioniert für alle .NET Projekte
✅ Wird NICHT in Git eingecheckt


---
OPTION 3: appsettings.Development.json (NUR für Tests)
---
Connection String direkt eintragen:

{
  "ConnectionStrings": {
    "DefaultConnection": "Server=tcp:delikatessendrehbuch..."
  }
}

⚠️ ACHTUNG: NIEMALS in Git committen!
⚠️ Datei zu .gitignore hinzufügen!


========================================
EMPFEHLUNG: User Secrets (Option 1)
========================================

Wo wird der Secret gespeichert?
• Windows: %APPDATA%\Microsoft\UserSecrets\<user_secrets_id>\secrets.json

Wie kann ich ihn ansehen?
• dotnet user-secrets list

Wie kann ich ihn löschen?
• dotnet user-secrets remove "ConnectionStrings:DefaultConnection"
