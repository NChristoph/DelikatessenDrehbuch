Name der Verwendeten Sessions zum speichern der Ids der ausgewählten Rezepte:
{
		Der Name der Session für die gefilterten Rezepte nach (PersonalMealPlanSettings)
		ist die Kategorie.
		Zu der es gehört, "Vorspeise", "Hauptgericht", "Dessert"
		Wobei z.B. Vorspeise auch nur Vorspeisen in der Session speichert.

		Für Vegetarische Rezepte wird in der Session unter "PreferablyVegetarian" gespeichert.
		Für Rezepte mit Fleisch wird in der Session unter "PreferablyMeat" gespeichert.

		Der Gesamte Essensplan wird als "MealPlanList" in einer Session gespeichert
		die eien Liste vom Type PersonalMealPlanModel ist wobei ein Parameter den Index 
		darstellt der den Tag an den dieses Rezept gekocht wird dastellt.
}
